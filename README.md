# TotalFreedomMod #

> **UNMAINTAINED - SECURITY RISK**
> This project is no longer maintained. Critical vulnerabilities exist in the HTTPD feature (enabled by default). **Do not use binaries or builds from this repository in production.** Use at your own risk.
> Details: [SECURITY.md](SECURITY.md) · [Security Advisories](https://github.com/TotalFreedom/TotalFreedomMod/security/advisories)

*Travis CI is no longer active for this repository.*

TotalFreedomMod is a CraftBukkit server plugin originally designed primarily to support the [Official TotalFreedom Minecraft Server](http://totalfreedom.me/). The source remains available for historical reference and for others to adapt at their own risk.

This plugin was originally coded by StevenLawson (Madgeek1450), with Jerom van der Sar (Prozza) becoming heavily involved in its development some time later. It consists of over 85 custom coded commands and a large variety of distinguishable features not included in any other plugin.

### Download ###
**Not recommended.** Historical binaries may still appear on the [releases page](https://github.com/TotalFreedom/TotalFreedomMod/releases). Treat them as unsafe for production use. See [SECURITY.md](SECURITY.md) and any [security advisories](https://github.com/TotalFreedom/TotalFreedomMod/security/advisories). Prefer a maintained fork that has been independently audited.
